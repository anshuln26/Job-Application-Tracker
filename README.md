# Job Application Tracker

A modern web application built with React and Vite to track and manage job applications, interview schedules, offer comparisons, and status analytics.

## Features

- **Kanban Board**: Drag-and-drop or status-based application tracking.
- **Analytics View**: Visual insights on your application status breakdown.
- **Calendar View**: Keep track of upcoming interview schedules and deadlines.
- **Offer Comparer**: Compare compensation, perks, and benefits across multiple job offers.
- **Stats Overview**: High-level summary of your job search progress.

## Tech Stack

- **Frontend**: React, Vite
- **Styling**: CSS Modules / Custom CSS
- **Linting**: Oxlint

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/anshuln26/Job-Application-Tracker.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
